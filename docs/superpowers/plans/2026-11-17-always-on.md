# Always-on Agent Implementation Plan

**Goal:** 本地单用户公开资料监控，完整覆盖事件、计划、变化、通知和关联追问。
**Architecture:** SQLite owns durable jobs and business IDs; Pi SessionManager owns conversations. Express serves a small Chinese UI. A two-worker polling scheduler claims persisted runs and serializes each task.
**Tech Stack:** Node >=22.19, TypeScript, node:sqlite, Express, Pi Coding Agent 1.5.2, native HTML/CSS/JS.
**Spec:** 本会话用户授权的九项产品范围。

## Constraints and review focus

- No arbitrary shell/filesystem tools or global extensions; public HTTP(S) text only.
- Credentials stay server-side; bind loopback and reject foreign browser origins.
- Restart coalesces missed schedules, marks in-flight work interrupted, never silently replays chats.
- URLs: redirects, IPv6/mapped addresses, DNS rebinding, size/time bounds.
- Deterministic hashes, event IDs and notification keys own deduplication.
